# AVC app (built on the original HTML + CSS version)
Open index.html. Files: index.html (content), styles.css (look; section 14 = AVC polish), app.js (optional extras).
- Edit EVERY sample item (classes, staff, events, news) by hand; they are placeholders.
- Logo: drop official logo at assets/logo/logo.svg, unedited, with clear margin.
- Fonts: optional Gotham-Light.woff2 / Gotham-Medium.woff2 in assets/fonts (Arial fallback otherwise).
- Photos: replace assets/images/*.svg covers (or change the img src in index.html).
- Countdown date: COUNTDOWN in app.js.
